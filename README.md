# Multi-Cohort Cross-Omics Analysis of HAM

This repository hosts the main scripts used for running analyses for our manuscript: *Multi-cohort cross-omics analysis reveals disease mechanisms and therapeutic targets in a neglected retroviral neuroinflammatory disorder, HTLV-1-associated myelopathy*.
